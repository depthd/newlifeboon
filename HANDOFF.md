# Передача работы по физике автомобиля

Репозиторий `depthd/newlifeboon`, ветка `codex/car-physics-01`, база `c9faa71`. Снимок работы перед этой передачей — `5cb441e`. [Черновой PR №1](https://github.com/depthd/newlifeboon/pull/1)

## Цель и результат

Проверить устойчивость существующей физики Viper и Logan, устранить потерю движения в свободном полёте и выяснить, подходит ли Jolt для следующего этапа работы над контактами и подвеской.

- `2184021` — диагностика исходной модели и сравнение открытых движков. При исчезновении опоры под одной стороной текущая игровая модель может подбросить кузов на несколько метров. Высота выброса сильно зависит от шага расчёта.
- `8492b41` — наземные помощники перестали обнулять горизонтальную скорость и гасить рысканье без опоры колёс. Проверка обеих машин в свободном полёте сначала выявила ошибку, после исправления прошла на 300 и 600 Гц.
- `5cb441e` — отдельный стенд Viper на Jolt. Покой и потеря двух опор проходят на 240, 480 и 960 Гц. Максимальный дрейф за 30 секунд — 0,92 мм. При снятии двух опор кузов падает с края без подъёма выше начальной высоты. Node и Chromium дали одинаковые результаты всех 12 сценариев.

## Как проверить

```bash
npm ci
npm run car
npm run drive
npm run build
npm run --silent car:contacts
npx playwright install chromium
npm run --silent car:contacts -- --browser
npm run --silent car:contacts -- --broken
```

Штатные `car`, `drive` и сборка прошли. Браузерный режим принимает `CHROMIUM_PATH`, если используется системный Chromium. Стенд печатает JSON. Код выхода 1 в обычном и браузерном режимах вызван превышением хода в четырёх из шести сбросов. Режим `--broken` задаёт вертикальную скорость +5 м/с и проверяет, что искусственный выброс обнаруживается. Таблица результатов и условия замеров сохранены в [журнале физики](docs/car-physics-progress.md).

## Открытые проблемы и точка продолжения

При сбросе с 2 м на 240 Гц подвеска Jolt выходит за предел хода на 9,71 мм при допуске 1 мм. Следующий самостоятельный шаг — проверить отбойник и податливость контакта на тех же сбросах, сохраняя покой и поведение на краю. Контакты в игре по-прежнему считает прежний решатель. Для него остаются проблемы частичной опоры, удержания на уклоне и зависимости ввода и вращения колёс от частоты показа. Достоверность шин и переходных манёвров на стенде ещё предстоит измерить.
