# Передача работы из чата 42

Ветка `wip/traffic-life-chat42` сохраняет работу этого облачного чата по состоянию на 22 ноября 2026 года. Исходная точка — `c9faa71`. Код и результаты работы над физикой уже сохранены коммитом `ec6ddc4`.

## Цель и статус

Чат закреплён за трафиком и симуляцией жизни `newlifeboon`. Изменений по этому направлению здесь нет. В этой рабочей копии сохранился отдельный этап автомобильной физики. Пользователь остановил его и попросил сохранить результат для передачи исполнителю физики и Astra. Ведущий этот разбор может сравнивать ветку с другими работами по физике до принятия решения об интеграции.

## Что сделано

- Убрано принудительное обнуление малой скорости. Машина может скатываться по уклону без тормоза и сохраняет горизонтальное движение в воздухе.
- Исправлен знак аэродинамического прижима и его двойной учёт в нагрузке колёс. Пустота обозначается `Spot.present=false`, чтобы кузов и колёса оставались без опоры.
- Приложение и расчётные проверки используют шаг 1/600 с. На нём обновляются клавиатурный ввод и вращение колёс. Исправлено округление на границе шага.
- Добавлены телеметрия двигателя и проверки частичной потери контакта, падения, проезда неровности и манёвра при 30, 60 и 144 Гц.

## Как проверить

Из корня репозитория:

```sh
npm ci
npm run types
npm run build
npm run car
npm run drive
npm run drive -- сломать
node tools/car-frames.mjs --visual
```

`drive -- сломать` должен завершиться кодом 1. Для установленного системного Chromium можно задать `CHROMIUM_PATH=/usr/bin/chromium`. Предыдущий прогон подтвердил сборку, типы, `car`, `drive` и совпадение координат, скорости и времени манёвра при 30, 60 и 144 Гц. Записано 16 кадров кувырка Viper с телеметрией. Подробности в `docs/car-physics-progress.md`. Исходные логи и кадры сохранены в облачном окружении в `/workspace/work/car-physics-handoff.tar.gz`. Для снимка Git учитываются файлы репозитория, архив хранится отдельно.

## Что осталось и зависимости

- На уклоне 10% с ручником за 10 с Viper смещается на 8,5 см, Logan — на 37,1 см. Нужна модель удержания шины при малой скорости. Пробное изменение затухания ухудшило результат и было отменено.
- Проверка плавности уложилась в численный порог, но завершилась ошибкой захвата указателя в Chromium. Полная браузерная поездка `ride` остановлена до итогового результата. Полная калибровка подвески и управляемости остаётся открытой.
- При сравнении с ветками трафика и физики проверьте пересечения в `src/main.ts` и `src/car/ground.ts`. Столкновения с городским трафиком остались покадровыми. Интерфейс телеметрии может использовать задача звука двигателя. Для сборки ветки отдельная ветка звука или трафика не требуется.
