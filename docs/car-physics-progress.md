# Физика автомобиля — текущий этап

## 2026-11-22 — стенд контактов Viper на Jolt

В отдельном стенде проверены покой, исчезновение опоры под правой стороной и вертикальные сбросы с 0,5 и 2 м. Модель основана на геометрии паспорта Viper, масса 1605,4 кг (1530,4 кг для GTS Track Package и 75 кг водителя). Вся масса входит в твёрдый кузов. Его форма и инерция приближены коробкой, вертикальное движение колёс задают подвеска и поиск контакта цилиндром. Жёсткость и демпфирование взяты из расчёта `cornerSpring` для полной массы, без отдельной неподрессоренной массы. Трение колёс штатное для Jolt, водительский ввод нулевой. Установка экспериментальная. Игровой автомобиль по-прежнему использует `src/car/car.ts`.

После 3 с установления проверяем 30 с покоя, 2 с после удаления правой плиты или 5 с после сброса. Стенд требует дрейф в покое ≤1 см, сумму реакций в пределах 1% веса, две левые опоры сразу после удаления правой плиты, подъём центра масс при потере опоры ≤5 см, выход за пределы хода ≤1 мм и проникновение кузова на полной плоскости ≤2 см. В сбросах также проверяются контакт после свободного падения, возврат к покою и высота относительно точки отпускания. Полный энергетический баланс, качество сцепления и рендер колёс остаются предметом дальнейших проверок.

| Частота | Подъём при потере двух опор, Jolt / текущая модель | Превышение хода при сбросе 0,5 м | Превышение хода при сбросе 2 м |
| --- | --- | --- | --- |
| 240 Гц | 0 / 8,28 м | **3,85 мм** | **9,71 мм** |
| 480 Гц | 0 / 0,58 м | **1,33 мм** | 0,94 мм |
| 960 Гц | 0 / 7,23 м | 0,85 мм | **2,42 мм** |

Текущая модель повторно замерена на `8492b41`. Сценарий имеет то же снятие опоры, но сравнение не контролирует различия в массе, кузове и геометрии края. В Jolt кузов опрокидывается и падает с края. Стенд проверяет именно отсутствие катапульты.

Node 24 и Chromium 156 вернули одинаковые строки измерений, в Chromium ошибок страницы 0. Покой и потеря двух опор прошли на всех частотах. Наибольший дрейф за 30 с — 0,92 мм, ошибка суммы реакций <0,001% веса. При сбросах проникновения коробки не зафиксировано, кузов вернулся в покой. Четыре из шести приземлений превысили допуск хода. При 2 м переход с 480 на 960 Гц увеличил превышение, поэтому одно уменьшение шага результата не гарантирует. Отрицательный контроль с начальной вертикальной скоростью +5 м/с дал подъём на 1,264 м и провал проверки катапульты. `npm run car`, `npm run drive` и `npm run build` прошли.

Запуск после `npm ci`:

```bash
npm run --silent car:contacts
npm run --silent car:contacts -- --browser
npm run --silent car:contacts -- --broken
```

Браузерный режим использует Chromium от Playwright (`npx playwright install chromium`) или путь в `CHROMIUM_PATH`. Все три команды сейчас печатают JSON и завершаются кодом 1 по описанным нарушениям. Для штатного стенда это превышение хода, для отрицательного контроля — искусственный выброс и превышение хода. Локальные отчёты — `/workspace/work/car-contact-stand/{node,chromium,negative,legacy-half-support}.json`. `jolt-physics@1.1.1` (MIT) используется как зависимость инструментов. Стенд удаляется одним обратным коммитом.

Следующий шаг — отдельно проверить модель отбойника и податливость контакта на тех же сбросах. Цель — уложиться в 1 мм на 240/480/960 Гц с сохранением покоя и устойчивости края. До этого результат стенда непригоден для переноса контактной модели в игру.

Начальная поза явно выровнена, чтобы главная ось совпадала с вертикалью; допуск не ослаблялся.

Проверены `npm run drive` (код 0), `drive -- сломать` (ожидаемый код 1, прежние три нарушения), сборка с обеими проверками типов (код 0) и повторная проверка типов после расширения сценария (код 0). В браузере повторены движение/салон/бросок: 230 отсчётов, 12 диагностических кадров, page errors 0. Материалы после фикса — `visual-after-flight/`, `browser-after-flight.log`, `free-flight-before.log`, `free-flight-after.log`, `free-flight-negative.log`, `build-after-flight.log`, `types-after-flight.log` в папке артефактов.

## Проверенные результаты

- Собственная физика, а не внешний движок. В игре 300 Гц; в `tools/drive.ts` 600 Гц.
- Штатные `car`, `drive` и `build` прошли. Предусмотренные `car -- сломать` и `drive -- сломать` завершились с кодом 1, как требуется.
- Жалоба на разлетающиеся колёса в просмотренных сценариях исходного коммита не воспроизвелась. Центры колёс вычисляются из позы кузова; прежние исправления действительно есть в коде.
- Новый расчётный контрпример: неподвижная машина, исчезновение поверхности под правой стороной, 2 с без управления. На 300 Гц подъём Viper до 4.148 м, Logan до 15.306 м; при 150/120 Гц Logan получает NaN. Даже уменьшение шага до 1200 Гц не даёт сходимости. Сценарий/состояния сохранены; это не утверждение о каждом крае игровой карты.
- Полная пустота: свободное падение 2 с без NaN. Одно вывешенное колесо: конечность состояния у обеих машин. Вертикальный сброс 0.5 м конечен, но у Logan нагрузка на колесо достигает около 119 кН, что требует отдельной проверки реализма удара.
- Подтверждены принудительная остановка на 0.21 м/с и искусственное гашение вращения в воздухе. Латентный неверный знак прижимной силы не активен у двух нынешних паспортов с liftArea=0.
- Прямолинейные режимы на 300/600/1200 Гц близки, частичная опора — нет. Управление и вращение колёс имеют остаточную зависимость от частоты показа. На 5 кадрах/с ограничение dt допускает только 0.5 с симуляции на секунду часов.
- Приложение проверено в Chromium: разгон, тормоз, поворот, салон и 12 кадров броска/края. 223 отсчёта, page errors 0. Это ограниченная визуальная проверка, не приёмка всей модели.
- Physics-only Chromium benchmark: медиана 6.4 мкс/шаг на плоскости, 11.2 мкс с GroundIndex. Отдельная некалиброванная Jolt-проба 40 мкс/шаг; её автомобиль/контакты иные, сравнение не эквивалентно.

## Выбор и обоснование

Основной путь — собственный ограниченный автомобиль поверх Jolt Physics WASM: готовый решатель кузовных контактов/ограничений, осмысленные шины и силовая установка, сохранённые паспорта и согласованное отображение. `jolt-physics@1.1.1` проверен в Node и Chromium, включая cylinder casts и JS callback шин.

У Jolt MIT, Rapier Apache-2.0, cannon-es MIT, Chrono и PhysX BSD-3-Clause. Лицензии/первичные источники проверены. Ограничение Jolt: callback границ импульсов не равен прямой вставке прежней формулы сил; combined slip, нагрузку, релаксацию и покой ещё нужно доказать. Никакая миграция не выполнена.

Полная карта, ссылки, различие фактов/оценок и выбор: `docs/car-physics-research.md`. Это самостоятельный результат исследования; ожидать от него исправленного автомобиля нельзя.
