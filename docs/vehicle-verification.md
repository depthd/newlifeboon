# Как проверить Logan и Viper

В полигоне и городе за движение отвечает `src/car/car.ts`. Физика принимает паспорт машины, ввод, шаг времени и функцию, которая возвращает опору в точке мира. Рендер читает позу кузова и центры колёс. На испытательном овале покрытие аналитическое, в городе под колёсами находится геометрия сцен.

## За руль

В Node 24 выполните `npm ci` и `npm run dev`. Откройте указанный адрес и добавьте `/trial.html` для полигона. На прямой зажмите D, затем сразу нажмите A. Сравните «Быстрый» и «Прежний» руль с одной машиной и одинаковой скоростью старта. Быстрый руль быстрее проходит через ноль и ограничивает угол на скорости. Полигон начинает движение с 45 км/ч, для прежнего испытания выберите 60 км/ч. Для теста шин поверните у трёх конусов вправо. После двух попыток можно раскрыть настройки и скачать запись. Собрать автономный HTML можно через `node tools/build-trial.mjs`. Для игры в городе откройте корневой адрес.

## Измерения

Из корня проекта, после `npm ci`, в Bash выполните

```sh
mkdir -p build/verification
npm run build
npm run car
npm run drive
npm run car:steering
npm run car:ledges -- --json build/verification/ledges.json
node tools/contact-audit.mjs . build/verification/contacts.json
node tools/road-matches.mjs . build/verification/road
node tools/handling.ts build/verification/handling
```

Команда `car:ledges` проверяет 180 положений у составной и криволинейной кромки, 36 случаев на треугольниках игровой поверхности и 12 случаев с балкой или пустотой под кузовом. После потери опоры отслеживаются две секунды движения. Допуск подъёма центра масс составляет 5 см. Проверяются нагрузки отдельных колёс в первый шаг, удержание кузова на балке при вывешенных колёсах и высота падения без опоры. При нарушении команда завершается с кодом 1.

В отчётах есть условия каждого опыта и отдельные результаты. Установив NumPy и matplotlib, можно построить графики через `python tools/handling-plots.py build/verification/handling`. Браузерную проверку города запускает `CHROMIUM_PATH=/usr/bin/chromium npm run ride`. Замените путь на установленный Chromium либо используйте Chromium Playwright. Управление на 30/60/144 кадрах/с проверяет `node tools/car-frames.mjs`.

Замеры Edmunds служат для настройки Viper. Отложенные замеры Car and Driver используются для проверки другого испытанного экземпляра. Для Logan есть грубая независимая проверка разгона по раздельным отрезкам до 80 и до 100 км/ч. Сопоставимость остановки Logan II с данными первого поколения ограничена. [Edmunds](https://www.edmunds.com/car-reviews/track-tests/2013-srt-viper-gts-track-test.html) · [Car and Driver](https://www.caranddriver.com/reviews/comparison-test/a15117228/2013-srt-viper-gts-vs-2013-chevrolet-corvette-zr1-comparison-test/) · [Авто Mail](https://auto.mail.ru/article/54096-vosmiklapannoe-serdtse-dlitelnyij-test-renault-log/)

## Шаги и исходные версии

1. Базовая игра `c9faa71` сохраняет четыре пятна контакта, паспорта, подвески и рендер кузова.
2. Из `ec6ddc4` пришли общий шаг 600 Гц, признак отсутствия поверхности, учёт аэродинамического прижима и телеметрия двигателя. Подход к свободному вращению в воздухе восходит к `8492b41`.
3. Для кузова при обрыве используются геометрия локальной кромки и контактные импульсы. У ручника есть ограничение силы трением и доступным тормозным моментом. Пространственный решатель Jolt из `5cb441e` проверен на отдельном стенде.
4. Для Viper выбрана комплектация GTS Track Package, снаряжённая масса 1530,4 кг плюс условные 75 кг водителя. У обеих машин ABS регулирует тормозное давление. Темп набора давления и эффективное сцепление шин остаются приближениями.
5. Штатная шина и привод действуют в обычной машине. Варианты баланса нарочно уменьшают только поперечное сцепление одной оси на 40%. В режиме сравнения помощи параметры осей штатные.
