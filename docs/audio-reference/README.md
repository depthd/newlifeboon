# Зафиксированная основа и исходный эксперимент

- Проект: `depthd/newlifeboon`, база `c9faa71a16fde48c2beb0db362189b82bb958149`.
- Upstream: [Antonio-R1/engine-sound-generator](https://github.com/Antonio-R1/engine-sound-generator),
  commit `c76c5adb9e63f5a54fb0def3b97e8e0ac1a7dea1`.
- Исследованный файл:
  `src/engine_sound_generator/engine_sound_generator_worklet.js`.
- `upstream-worklet.js` — сохранённый исходник процессора; исполняемая логика не
  изменена. Полный MIT-текст хранится в `LICENSE-Antonio-R1`.
- `check-throttle.cjs` — изолированный Node VM-прогон с одинаковым seed шума.
- `results.json` — исходный результат исследования, не новый браузерный тест.

Воспроизведение: `node docs/audio-reference/check-throttle.cjs` из корня проекта.
При 3000 RPM сравниваются throttle 0 и 1 на трёх выходах при 44,1 и 48 кГц.
Исходный результат: максимальная разность отсчётов равна нулю в обоих случаях.
Положительный контроль меняет RPM до 3300 и обнаруживает различие. Node-проверка
показывает отсутствие влияния параметра в этой версии алгоритма, но не доказывает
браузерную производительность или качество тембра.

В новом `src/audio/engine-dsp.js` генератор существенно адаптирован: разделены
часы и UI, изменены фазы клапанов и импульса, добавлено управление возбуждением
через load01, физические времена задержек, частотно-независимые фильтры/сглаживание,
механический компонент и контролируемый уровень. Поэтому старые результаты не
являются результатами проверки нового алгоритма.
